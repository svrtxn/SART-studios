# SART Eco

This project consists of a backend server built with NestJS and a frontend application built with Angular.

## Prerequisites
- Node.js (v18 or higher recommended)
- npm

## Getting Started

To run the full application, you need to start both the backend and the frontend in separate terminal windows.

### 1. Backend (NestJS)

Open a terminal and navigate to the `backend` directory:

```bash
cd backend
```

Install the dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run start:dev
```

The backend server will start and watch for any file changes.

### 2. Frontend (Angular)

Open a new terminal window and navigate to the `frontend` directory:

```bash
cd frontend
```

Install the dependencies:

```bash
npm install
```

Start the Angular development server:

```bash
npm start
```

The application will be accessible at `http://localhost:4200/`.
