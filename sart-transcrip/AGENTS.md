# SART STUDIOS Project Agent

Before making any change, read:

- design-system/master.md

This document references the complete Design System.

Rules:

- Never create new colors.
- Never create new spacing values.
- Never create new typography.
- Always reuse documented components.
- Always follow UX principles.
- Maintain visual consistency across the project.
- **CSS STRICTNESS**: NEVER hardcode CSS values (colors, shadows, radiuses). ALWAYS use the CSS variables defined in the system. Follow flexbox layout standards. See `design-system/css.md` for exact rules.

If a design rule is missing, extend the Design System instead of inventing a new one.
